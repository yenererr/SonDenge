# Level2 sesleri

Bu klasörün Level2 sesleri dışarıdan indirilen dosyalar yerine oyun çalışırken kısa sentetik dalga formlarıyla üretilir.

Üretilen sesler:

- Mobilya satın alma: kısa, yükselen iki notalı bildirim.
- Mobilya yerleştirme: yumuşak vurgu ve kısa onay sesi.
- Yerleştirme iptali: alçalan kısa uyarı sesi.

Bu nedenle harici kaynak veya lisans atfı gerektiren bir ses dosyası kullanılmaz.
